# Simple E-Commerce Website (Java + Maven)

A small beginner-friendly web application built with Java 17, Spring Boot, Maven and Thymeleaf.

## Features
- Display a small product catalogue
- Add products to a session-based shopping cart
- View quantities and cart total
- Remove products
- Place a demo order
- Unit tests for product and cart services

## Requirements
- JDK 17 or later
- Maven 3.6+ (or use the Maven wrapper generated by your IDE)

## Run the application
From the project root:

```bash
mvn spring-boot:run
```

Open http://localhost:8080 in your browser.

## Run tests

```bash
mvn test
```

## Build a JAR

```bash
mvn clean package
java -jar target/simple-ecommerce-1.0.0.jar
```

## Learning note
This is a learning/demo project, not a production-ready store. It does not include login, a real database, payment processing, stock management, or order persistence. The product list is stored in Java memory and the cart is stored in the user's HTTP session.
